# Joulukalenteri

Teemajoulukalenteri, johon haetaan käyttäjän syöttämän hakusanan perusteella kuvat Finnasta. Kalenterin kuvat ja tila tallentuvat localStorageen. Avattuja luukkuja klikkaamalla tulee näkyviin lisätietoja. Voit kokeilla sovellusta täällä: https://ruulnoke.github.io/teemajoulukalenteri/.
